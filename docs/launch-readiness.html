The tarball gate — what's new

The problem it closes: npm test exercises the working tree, so it can't catch a file missing from package.json files:, a runtime dep that only resolves from a dev node_modules, or a node-pty spawn-helper that crashes on a fresh install — exactly the bugs that turn a clean local run into a broken npx. verify-pack tests the published artifact instead.
